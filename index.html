Kullanım Kılavuzu & C Referansı

Akış Şeması Blokları ve C Karşılıkları

C dilindeki temel kontrol yapıları standart geometrik akış blokları ile modellenir:

Oval Başla (Oval)

C dilindeki int main() fonksiyonunun girişidir. Akış her zaman bu bloktan başlar.

Dikdörtgen İşlem / Atama (Dikdörtgen)

Değişken tanımlama ve hesaplamalar yapılır. Kompakt kullanım için birden fazla atama virgül (,), noktalı virgül (;) veya yeni satır ile yazılabilir (ör. a = 5\nb = 10\ntoplam = a + b).

Paralelkenar Girdi (Paralelkenar / scanf)

Kullanıcıdan klavye ile dinamik değer alır. Birden fazla değişken virgülle yazılabilir (ör. a, b, c).

Baklava Karar / Koşul (Baklava / if-else)

Mantıksal bir şartı değerlendirir. Şart doğruysa sol çıkıştan (Doğru / True), yanlışsa sağ çıkıştan (Yanlış / False) devam eder.

Altıgen Döngü (Altıgen / for-while)

Sayaçlı döngü bloğudur: değişken = başlangıç, bitiş, adım (ör. i = 1, N, 1). Sağ üst çıkış Gövde (Body), sağ alt giriş Dönüş (In), alt çıkış ise Çıkış (Exit) portudur.

Belge Çıktı (Belge / printf)

Konsola metin veya değişken değeri yazdırır (ör. "Sonuç: " + toplam veya x * 2).

Oval Bitiş (Oval)

C dilindeki return 0; ifadesidir. Akış bu bloğa ulaştığında program başarıyla sonlanır.

C Veri Tipleri (Otomatik Tip Çıkarımı)

Yorumlayıcı, atanan değerleri analiz ederek C türlerini otomatik belirler ve bellek tablosunda canlı gösterir:

int int (Tamsayı)

Ondalık kısmı olmayan pozitif ve negatif tamsayılar. Örnek: x = 42, sayac = -5.

double double / float (Kayan Noktalı Sayı)

Ondalıklı reel sayılar. Nokta (.) karakteri ile yazılır. Örnek: pi = 3.14159, oran = 0.5.

bool bool (_Bool / Mantıksal)

Mantıksal doğruluk değerleri: true (1) veya false (0). Örnek: asal = true, bulundu = false.

char[] char[] (Metin Dizisi / String)

Çift tırnak ("...") içindeki metinler. Çıktılarda metin ve sayılar + operatörü ile birleştirilebilir (ör. "Alan: " + alan).

Operatörler & İfade Kuralları

C standardına uygun tüm temel operatörler güvenli AST ayrıştırıcı ile çalıştırılır:

Aritmetik Operatörler

  • Toplama (a + b)
  • Çıkarma (a - b)
  • Çarpma (a * b)
  • Bölme (a / b)
  • Kalan / Modulo (a % b)

Karşılaştırma / İlişkisel Operatörler

  • Eşit mi? (a == b)
  • Eşit değil mi? (a != b)
  • Küçük mü? (a < b)
  • Küçük veya eşit mi? (a <= b)
  • Büyük mü? (a > b)
  • Büyük veya eşit mi? (a >= b)

Mantıksal Operatörler

  • Mantıksal VE (a && b)
  • Mantıksal VEYA (a || b)
  • Mantıksal DEĞİL (!a)
İşlem Önceliği & Parantezler

Matematiksel işlem önceliği: Parantez () > Çarpma/Bölme/Mod * / % > Toplama/Çıkarma + - > Karşılaştırma > Mantıksal VE/VEYA. Örnek: (a + b) * (c - d).

Çalıştırma & Gelişmiş Özellikler

  • Çalıştır (Play): Akışı belirlenen gecikme süresinde otomatik adımlarla baştan sona çalıştırır.
  • Adımla (Step): Akışı tek bir düğüm ilerletir, aktif düğümü ve takip eden bağlantı yolunu vurgular.
  • Duraklat (Pause): Sürekli çalıştırmayı durdurur; kaldığınız yerden Adımla veya Çalıştır ile devam edebilirsiniz.
  • Sıfırla (Reset): Değişken belleğini ve konsolu temizleyerek Başla düğümüne döner.
  • Doğrudan Yeniden Başlatma: Program bittiğinde sıfırlamaya basmadan doğrudan Çalıştır veya Adımla düğmesine basarak yeniden başlatabilirsiniz.
  • Adım Gecikmesi (Slider): 0 ms (Anında) ile 2000 ms arasında gecikmeyi dinamik olarak değiştirir.
  • Otomatik Düzenle (Auto-Layout): Düğümleri otomatik hizalar, temiz dikey Manhattan 90° bağlantı hatları çizer.
  • Kaydet & Yükle: Hazırladığınız akış şemasını .json formatında dışa aktarabilir veya daha önce kaydettiğiniz dosyayı yükleyebilirsiniz.
